# Time Tracker

**Простой трекер времени для ваших задач** ⏱️

Запускайте секундомер, указывайте, над чем работаете, и смотрите, куда уходит время.

</div>

---

## ✨ Возможности

- ⏱️ **Секундомер** с запуском, паузой и продолжением
- 📝 **Название задачи**: всегда понятно, над чем вы работаете
- 💾 **Сохранение записей**: нажмите «Стоп и сохранить», и запись попадёт в историю
- 📊 **Общий итог**: сколько времени вы потратили в сумме
- 🗑️ **Удаление записей**, если что-то записалось по ошибке
- 🔖 **Время в названии вкладки**: следите за таймером, даже когда работаете в другом окне
- 📱 **Адаптивный дизайн**: удобно и на компьютере, и на телефоне
- ⌨️ **Работа с клавиатуры**: `Enter` запускает таймер, `Tab` переключает кнопки

## 🚀 Как пользоваться

1. ✍️ Введите название задачи, например «Подготовить отчёт»
2. ▶️ Нажмите **Старт** или клавишу `Enter`
3. ⏸️ Нужен перерыв? Нажмите **Пауза**, а потом **Продолжить**
4. ⏹️ Закончили? Нажмите **Стоп и сохранить**
5. 📚 Запись появится в разделе **История**

> 💡 **Совет:** название и время отображаются в заголовке вкладки браузера, например `00:12:45 | Подготовить отчёт | Time Tracker`.

## 🔒 Ваши данные

Все записи хранятся **только в вашем браузере** (в `localStorage`). Они не отправляются на сервер и не требуют регистрации.

- ✅ После перезагрузки страницы записи остаются
- ⚠️ Если очистить данные сайта в браузере, история пропадёт
- ⚠️ В другом браузере или на другом устройстве история будет пустой

## 💻 Запуск на своём компьютере

Понадобится [Node.js](https://nodejs.org/) последней LTS-версии.

```bash
# 1. Установите зависимости
npm install

# 2. Запустите приложение
npm run dev
```

После этого откройте в браузере адрес, который появится в терминале (обычно `http://localhost:5173`) 🎉

### Сборка для публикации

```bash
npm run build     # собрать проект
npm run preview   # посмотреть собранную версию
```

Готовые файлы появятся в папке `dist`, их можно разместить на любом статическом хостинге.

## ❓ Частые вопросы

<details>
<summary><b>Таймер сбросится, если я закрою вкладку?</b></summary>

Да. Незавершённый таймер не сохраняется, сохраняются только записи, которые вы завершили кнопкой «Стоп и сохранить».

</details>

<details>
<summary><b>Почему не сохранилась запись?</b></summary>

Записи короче одной секунды не сохраняются, чтобы история не засорялась случайными нажатиями.

</details>

<details>
<summary><b>Таймер точно считает время, если вкладка в фоне?</b></summary>

Да. Время считается по системным часам, поэтому остаётся точным. Название вкладки в фоне может обновляться с небольшой задержкой, это особенность браузеров.

</details>

<details>
<summary><b>Можно ли изменить название задачи после запуска?</b></summary>

Пока таймер активен, поле заблокировано. Название можно задать только перед стартом.

</details>
